# POS CLI System

A simple Command-Line Point of Sale (POS) system developed using Java, applying Object-Oriented Programming (OOP) concepts.

## Features

- Product management
- Product details and pricing
- Shopping cart management
- Quantity management
- Order processing
- Bill calculation

## Technologies Used

- Java
- Object-Oriented Programming (OOP)
- Command-Line Interface (CLI)

## How to Run

1. Clone this repository:

   ```bash
   git clone YOUR_REPOSITORY_URL
   ```

2. Open the project in your preferred Java IDE.

3. Compile the Java source files.

4. Run the main class to start the application.

## Purpose

This project was developed to practice Java programming and understand OOP concepts through a simple POS application.
